WHATSAPP:

ADMINISTRACIÓN:
Hay un panel básico al final de la página, con clave inicial SGadmin2026.
IMPORTANTE: este panel solo guarda cambios en el navegador del dispositivo donde se edita. No sincroniza cambios con otros visitantes y la clave no es segura porque el código es público. Para una administración real compartida desde cualquier dispositivo, se necesitaría una base de datos y autenticación en un servicio backend. Cambia ADMIN_KEY antes de publicar, pero no uses este panel para datos sensibles.

PUBLICAR GRATIS CON GITHUB PAGES:
1. Crea una cuenta en GitHub.
2. Crea un repositorio, por ejemplo streaming-global-web.
3. Sube index.html y logo-streaming-global.png a la raíz.
4. En Settings → Pages, elige “Deploy from a branch”.
5. Selecciona la rama main y /(root), guarda.
6. Espera a que aparezca la URL pública en Settings → Pages.

ANTES DE PUBLICAR:

- La web no procesa pagos ni guarda pedidos.
